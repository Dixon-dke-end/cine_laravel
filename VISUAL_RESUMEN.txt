│                                                                                  │
│  4. BACKEND VERIFICA CON FILTRO                                                 │
│     └─ Busca en BD: estado != 'cancelada'                                       │
│     └─ Si encuentra: ocupada = true                                             │
│     └─ Si no encuentra: ocupada = false                                         │

│     └─ Si ocupada = true  → 🔴 ROJO                                            │
