    ├─ Valida datos
    ├─ Crea en tabla 'reservas'

    │  INSERT INTO reservas_sillas (reserva_id, silla_id) VALUES (1, 5)
    │  INSERT INTO reservas_sillas (reserva_id, silla_id) VALUES (1, 6)
    │  INSERT INTO reservas_sillas (reserva_id, silla_id) VALUES (1, 7)
    │
    ├─ Commit transacción (guarda todo)
    └─ Retorna JSON: {"success": true, "reserva": {...}}

7️⃣  JAVASCRIPT RECIBE RESPUESTA
    ├─ const data = response.json();
    ├─ if (data.success) {
    │   window.location.href = '/mis-reservas?success=true';

    └─ Redirige a página de confirmación
