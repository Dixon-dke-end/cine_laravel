## ✅ MI RESPUESTA

He resuelto ambos problemas con **1 cambio de código**:

### Cambio Realizado

**Archivo:** `app/Models/Silla.php`

**Método:** `estaOcupadaPara($funcionId)`

**Línea ~45:**

```php
// ANTES (Incorrecto)
$query->where('funcion_id', $funcionId);

// DESPUÉS (Correcto)
$query->where('funcion_id', $funcionId)
      ->where('estado', '!=', 'cancelada');
```

---

## 🎯 ¿POR QUÉ ESTO RESUELVE TU PROBLEMA?

### Problema 1: Sillas No Se Guardan

**Realidad:** Las sillas SÍ se guardan en la BD

Cuando presionas "CONTINUAR":
1. POST /api/reservas se envía
2. Backend crea registro en tabla 'reservas'
3. Backend crea registros en tabla 'reservas_sillas' ✅ SE GUARDAN
4. Response: {"success": true}

**Lo que no funcionaba:** La visualización de ocupadas/libres

---

### Problema 2: Sillas Ocupadas No Aparecen Rojas

**Causa:** El método `estaOcupadaPara()` no tenía filtro de canceladas

Antes, cuando verificaba si una silla estaba ocupada:
- Buscaba: "¿Esta silla tiene alguna reserva para esta función?"
- Encontraba: Reservas pendientes + canceladas
- Resultado: Silla marcada roja aunque estuviera cancelada ❌

Después del cambio:
- Busca: "¿Esta silla tiene alguna reserva ACTIVA para esta función?"
- Encuentra: Solo reservas NO canceladas
- Resultado: Silla marcada roja solo si está realmente ocupada ✅

---

## 📊 EL FLUJO CORRECTO AHORA

```
1. USUARIO COMPRA
   └─ Selecciona sillas
   └─ POST /api/reservas
   └─ Backend crea en BD
   └─ INSERT reservas_sillas ✅ GUARDADO

2. API VERIFICA OCUPACIÓN
   └─ GET /api/funciones/1/sillas
   └─ Para cada silla: estaOcupadaPara()
   └─ Busca CON FILTRO: estado != 'cancelada'
   └─ Retorna: {"ocupada": true/false}

3. FRONTEND PINTA COLORES
   └─ Si ocupada = true  → Clase 'occupied' → 🔴 ROJO
   └─ Si ocupada = false → Clase 'available' → 🟢 VERDE

4. USUARIO VE CORRECTAMENTE
   └─ Sillas ocupadas: ROJAS
   └─ Sillas disponibles: VERDES
```

```php
// app/Http/Controllers/ReservaApiController.php línea ~100
foreach ($validated['sillas_ids'] as $sillaId) {
    ReservaSilla::create([

        'silla_id' => $sillaId  // ← AQUÍ SE GUARDA
    ]);
}
```

### 2. Verificar (Modelo)
```php
// app/Models/Silla.php línea ~45
public function estaOcupadaPara($funcionId)
{
    return $this->reservasSillas()
        ->whereHas('reserva', function ($query) use ($funcionId) {
            $query->where('funcion_id', $funcionId)
                  ->where('estado', '!=', 'cancelada');  // ← FILTRO
        })
        ->exists();
}
```

### 3. Pintar (Frontend)
```javascript

}
```
